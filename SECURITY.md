# Security policy

## Report a vulnerability

Don't report security problems in public issues.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/Pesqueiro-GG/pesqueiro-gg/security/advisories/new). Include:

- What you found and where.
- Steps to reproduce it.
- What an attacker could do with it.

The team replies within 3 days during the hackathon period.

## What matters most here

Pesqueiro.GG handles fishing locations, which anglers treat as secrets. Reports about these are the highest priority:

- Exact catch coordinates reaching anyone other than the angler.
- Content visible to people outside its audience (groups or public).
- Photo metadata (such as GPS) surviving upload.
- Ways to award XP or rank without logging catches.

## Supported versions

Only the latest version on `main` is supported.
