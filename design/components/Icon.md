# Icon

A Lucide icon by name, drawn in the current text color.

- Icons come from Lucide 1.60.0 (ISC license): 24px grid, 2px stroke. In the app, use `lucide-react`; the names here match its components (`map-pin` is `MapPin`).
- Default 20px; 16px inside chips and badges; 22px in the bottom bar.
- Decorative by default (`aria-hidden`). Pass `label` only when the icon is the whole control and has no text.
- Put a word next to every icon, except share, close and the Log button. No emoji in the interface.
- `fishing-hook` is the reaction ("Fisgou"), `fish` a species or catch, `sparkles` marks a new sticker, `shield-check` a protected species, `camera` a photo-checked catch.
