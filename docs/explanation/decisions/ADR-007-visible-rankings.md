# ADR-007: Group rankings count only what the group can see

**Status:** Accepted · **Date:** 7 Nov 2026

## Context

Friends trust a ranking because they can see the catches behind it. Points from catches a group can't see would break that.

## Decision

A group's season ranking sums only XP from catches shared with that group or made public, plus challenge XP from that group's challenges.

## Alternatives considered

- One season XP number shown in every group

## Consequences

Every point can be checked by the people ranked. Scores can differ between groups, which the screen explains in one line.
