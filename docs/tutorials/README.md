# Tutorials

Tutorials are lessons: you follow every step and finish with something working, learning the project along the way.

There are no tutorials yet, because the app doesn't exist yet. They're written as soon as the code they teach is merged, so every step can be followed for real.

| Tutorial | You'll learn to | Available after |
|---|---|---|
| Run Pesqueiro.GG on your machine | Install, start the local database, seed the catalog and open the app | The app skeleton and database setup ([#2](https://github.com/Pesqueiro-GG/pesqueiro-gg/issues/2), [#3](https://github.com/Pesqueiro-GG/pesqueiro-gg/issues/3)) |
| Log your first catch end to end | Follow a catch from the form through the photo pipeline, species ID, the XP engine and the album | Logging a catch and earning XP ([#17](https://github.com/Pesqueiro-GG/pesqueiro-gg/issues/17), [#21](https://github.com/Pesqueiro-GG/pesqueiro-gg/issues/21)) |
| Add a new XP rule | Write a rule, test it, bump the ruleset version and replay | The XP engine ([#21](https://github.com/Pesqueiro-GG/pesqueiro-gg/issues/21)) |

Until then, start with [Pick up a backlog item](../how-to/pick-up-a-backlog-item.md).
